## English

*Prompts getting longer, the project drifting from what you first wanted?*

Arche (原语言, "the original language") is a seed language. It helps you pin down what you still want once every *how* is stripped away — as a seed any AI can grow from.

Give [原语言.md](原语言.md) to any AI (the file is in Chinese; it is written for your AI, not for you), then say:

- `开始：<your idea>` — "start": you have a vague idea and nothing else yet
- `归原` — "return to origin": you already have something (an old seed, code, an essay, a project that drifted)

Copy those two words exactly, write the rest in English, and ask it to reply in English. Guide: [原语言-使用说明.en.md](原语言-使用说明.en.md) · Example seed: [examples/Candlebreath.seed.md](examples/Candlebreath.seed.md) (Chinese original: [烛息](examples/烛息.seed.md))
